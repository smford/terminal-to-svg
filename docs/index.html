terminal-to-svg

Pixel-perfect terminal SVGs for documentation, GitHub READMEs, and CI/CD pipelines.

View on GitHub Release Notes (0.1.0)

Quick Install

# Install via Homebrew
brew install smford/tap/termtosvg

# Or install with Go
go install github.com/smford/terminal-to-svg/cmd/termtosvg@latest

# Or run via Docker
docker run --rm ghcr.io/smford/terminal-to-svg:v0.1.0 -version

Usage Modes

1. Live Screen Snapshot

Instantly captures what is currently rendered in your terminal window:

termtosvg -o snapshot.svg

2. Execute Command

Runs a command in a dedicated virtual PTY and renders the final frame:

termtosvg -o top.svg -- top -b -n 1

3. Stdin ANSI Pipe

Pipelines colored logs directly into crisp SVG diagrams:

cat build.log | termtosvg -o build.svg

4. Tmux Pane Capture

Capture any background or active tmux pane cleanly:

termtosvg -tmux "%1" -o pane.svg

Enterprise DevSecOps Features

  • Automatic Secret Masking: -mask-secrets redacts IPs, bearer tokens, JWTs, and passwords automatically.
  • Multi-tab Window Frames: Native rendering of multiple editor/tab panes via -tabs.
  • Subheader Cards & Badges: Display status labels, host names, and timestamps directly on the SVG header.
  • Continuous Compliance: Full OpenSSF Scorecard, Semgrep, CodeQL, OWASP ZAP, and Cosign verified artifact releases.
